# 已知限制与后续建议

> 2026-09-28 从 `winui3/README.md` 拆出来的归档，内容随实际情况更新。
> 使用者视角的当前状态请以 [../README.md](../README.md) 为准。

## 已知限制

- ~~**家庭版检测是硬阻断**~~（2026-10-25 已修）：原来 `RdpSessionService.DescribeEdition()`
  把「检测到家庭版」写进 `Readiness.Problems`，`CanConnect` 要求 `Problems.Count == 0`，
  于是用 RDP Wrapper 一类方案把家庭版开成服务端的用户也被拦住。
  现在版本判断整条移除，`EditionNote` 只用于展示系统版本名；「远程桌面是否开启」改成
  注册表开关不成立时再探测 3389 是否在监听（`IPGlobalProperties.GetActiveTcpListeners`），
  端口在听即判就绪 —— 比读 SKU 可靠，家庭版与专业版走同一条判据。

- **真机 GUI 验证尚未全覆盖**：构建环境在沙箱中无法启动 GUI，自动化部分靠 `dotnet build` + `_smoke` 源码级冒烟（770+ 项断言）；
  多通道并行、内嵌画面、多画面同屏等交互需要在真机上逐项验收（清单见计划书 §10）。
- **无 MSIX 打包**：unpackaged 模式直接跑 exe，如果需要商店分发要另建打包工程。
- **主题降级**：原 6 套 Qt 皮肤不保留，统一为系统 / 浅色 / 深色。
- **截图依赖 GDI+**：`System.Drawing.Common` 在 Windows 上可用，非 Windows 平台不支持（本工程本来就是 Windows-only）。
- **多画面每页最多 4 路**：8 路画面同时渲染的 CPU / GPU 开销不可接受，所以网格按 2×2 分页（翻页，不是滚动）。
- **弹出窗口没有独立入口**：画面弹成独立窗口后，要回去看它只能通过左侧菜单「会话通道」下该通道的子项；
  窗口本身只有关闭按钮（关闭后画面自动回页面里那一格）。
- **一次最多 8 条通道并行**（原生 `YCN_MAX_SESSIONS`）；超出的通道会被截断并明示原因。
- **真断线告警最迟 ~90 秒**：心跳判定把启动宽限期上限放在 90 秒（避免把正常的登录 + 代理拉起误报成失联），
  所以 90 秒内真掉线要到宽限期结束才会报。这是刻意的折中。
- **桥的 `command.json` / `status.json` 仍是 PascalCase**：与 `config.json` 的全 snake_case 约定不一致（历史遗留，待统一）。
- **收进状态栏不等于"任务在后台隔离运行"**：还是同一个进程，只是窗口不可见。退出仍然是进程结束 ——
  本地执行的任务会被清理，远程通道的任务在被控机上继续跑（这两件事在关闭弹窗里都写明了）。
- **多用户 RDP 切换导致当前会话被锁定期间，托盘图标不可见**：锁回来就恢复，不是故障。
- **托盘注册失败时不会静默隐藏**：会退成「最小化到任务栏」并在运行日志里写原因。
  这是刻意的 —— 静默隐藏会让用户以为程序关了，其实还在跑任务，再也找不回来。
- **主控端单实例的作用域是"本会话"**（`Local\` 命名互斥体）：同一台机器不同登录用户各开一份是允许的。
